NXT-Fitout — готовые страницы, CSS, JS, логотип, данные кейсов.

1) Распакуйте архив. Загрузите все файлы с сохранением путей (css/, js/, assets/, data/) в корень репозитория GitHub.
2) Не удаляйте прежнюю папку assets/uploads — оригинальные фото и видео могут находиться там. В архиве настоящие фото из GitHub НЕ включены, так как сервис не дал их скачать. Если фото отсутствуют, карточки покажут аккуратную заглушку.
3) Удалите старые файлы calculator.html, js/calculator.js, js/store.js и ВСЮ папку admin/ (если она есть), а также data/pricing.json. Проверьте и удалите старые админские ссылки из других пользовательских файлов.
4) В header/contacts WhatsApp ссылка сейчас https://wa.me/ (без номера), Instagram — https://www.instagram.com/ (общий адрес). Замените обе ссылки на свои в index.html и остальных HTML. НЕ указывайте вымышленные контакты.
5) Эти юридические страницы — короткие шаблоны, согласуйте юридические тексты до публикации.
6) Публикация GitHub Pages: Settings > Pages > Branch main / root. Подождите 1–5 минут, откройте сайт в режиме инкогнито.
7) Ссылка на исходный сайт: https://ahmetorunov743.github.io/NXT-Fitout/

ВАЖНО: GitHub Pages не позволяет автоматически распаковать ZIP в веб-интерфейсе. Сначала распакуйте его, затем загрузите файлы по папкам или воспользуйтесь GitHub Desktop на ПК.
