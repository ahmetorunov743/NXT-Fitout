Редактор проектов NXT Fitout

1. Откройте edit.html на компьютере или в браузере телефона.
2. Если список не загрузился, выберите файл data/cases.json вручную.
3. Создайте проект, выберите фото, заполните описание и нажмите «Сохранить проект в редакторе».
4. Для публикации без GitHub API скачайте cases.json и новые фото; разместите JSON в data/cases.json, фото в assets/uploads/.
5. Для прямой публикации заполните владельца, репозиторий, ветку и временный fine-grained GitHub token (Contents: Read and write для этого репозитория). Нажмите «Опубликовать на GitHub».
6. НЕ публикуйте edit.html в открытом репозитории: файл не защищён паролем, хотя без токена посетитель не сможет записывать данные в ваш репозиторий.
7. Токен нигде не сохраняется, после публикации поле очищается. Не делитесь токеном.
8. При работе с локальным файлом на телефоне прямой запрос к GitHub может зависеть от ограничений браузера. В этом случае используйте ручную загрузку или локальный HTTP-сервер.
9. Не закрывайте вкладку до публикации: неопубликованные изменения хранятся только в памяти открытой страницы.
10. Фото отображаются в уже существующем дизайне сайта; HTML и CSS сайта не менялись.
